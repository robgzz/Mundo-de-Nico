# Mundo de Nico V1 — Design System

## Core rule

**The interface behaves like Nico thinks.** Modern engineering is hidden underneath a warm, handcrafted storybook surface.

## Brand hierarchy

1. **El Mundo de Nico** — Nico-specific website/IP world.
2. **Entre dichos y aventuras** — parent creative universe.
3. Tagline: **Donde las palabras cobran vida.**

## Visual language

- Warm cream / paper base rather than sterile white.
- Deep ink blue for readability and continuity.
- Tomato red for Nico's energy and emphasis.
- Sun yellow for literal “aha!” moments and alerts.
- Sky blue for wonder / El Suspiro.
- Leaf green for outdoors / curious exploration.
- Imperfect paper edges, tape, doodles and notes provide human tactility.
- Motion is playful but never constant or noisy.

## Character use

Canonical visual identity always wins over website novelty. Character faces should come from approved artwork. CSS/SVG doodles may depict *motifs* (beetle, stone, puddle, Milo-like cat mark) but should not replace canonical character illustrations once final assets exist.

## Nico-specific motifs

- Rhinoceros beetles
- Smooth round stones
- Golden caps
- Puddles / “portals”
- Experiment numbering
- Handwritten annotations
- Red gelatin / vivid experiment materials
- Literal phrases transformed into visual events

## Interaction principle

Interactions should reward curiosity:

- words detach / shake / transform,
- doodles react subtly,
- experiments produce deterministic funny results,
- objects can reveal content,
- not every visual object needs to sell something.

## Mobile

Mobile is a separate composition, not a reduced desktop canvas:

- 44px+ touch targets,
- single-column story sequences,
- compact glass/paper navigation,
- reduced decorative density,
- no hover-only discovery,
- reduced-motion preference respected.
